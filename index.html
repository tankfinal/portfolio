關於我

工作、興趣，以及為什麼會有這些網站

我在 XREX 擔任 Backend Engineering Manager，帶一支五人的後端團隊。在這之前的十二年，我在 Binance 做交易資料管線、在製造業與遊戲產業做微服務、在系統整合商做過立法院、監察院、環保署、台大醫院的政府標案。Java / Spring Boot 是主軸，高併發、鎖與交易一致性是反覆練過的題目。

從工程師走到管理職之後，關心的問題換了兩個：這個設計三年後還撐得住嗎，以及團隊成員這季有沒有長出新東西。我相信技術決策要留得下記錄——為什麼選 A 不選 B，比選了什麼更重要。

下班後我寫的東西通常很小、很具體，而且都是自己真的會用的：出國前需要一份離線也能翻的行程，就做一個；女兒出生後要追 36 針疫苗，就做一個。共通點是零後端、零登入、一個網址打開就能用——因為要給家人用，不能有任何學習成本。另一條線是把重複的工作流程做成工具：MCP server、Claude Code 的 agent 團隊模板、可分享的 skill 集合，都在下面的開源區塊。

nueip-mcp

MCP

NUEiP 雲端人資系統的 MCP server。讓任何 MCP client（Claude Code、Claude Desktop）用自然語言查出勤、假期餘額、團隊請假與待簽核。密碼走 macOS Keychain，不落地。

agent-team

模板

Claude Code 的 Agent Team 模板。develop team（pm / be / fe，pm 刻意沒有寫檔權限，逼他派工）與 consult team（三位不同領域專家互相辯論）。用 tmux split pane 即時看所有 teammate 的對話。

外掛
